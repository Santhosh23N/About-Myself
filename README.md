## 🚀 How to Run Locally

### Option 1: Direct File Open
Double-click `index.html` in your file explorer, or open it with any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server
Run Python's built-in HTTP server from the `portfolio` folder:
```bash
python -m http.server 3000
```
Then visit:
```
http://localhost:3000
```
